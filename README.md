# BENZ BIZ Updates

Official Windows x64 installers for BENZ BIZ by BENZ OD.

Download the latest installer from this repository's Releases page. Existing BENZ BIZ installations can check releases through Settings → Updates.

Update feed: https://github.com/benzodol789-png/BENZ-BIZ-Updates/releases/latest/download/update.json

This distribution repository contains public installers, version metadata and release notes. No personal account records, connection credentials or development repository history are published here.

Each update manifest includes the installer version, HTTPS download URL, byte size and SHA-256 checksum. The app verifies the file before offering installation. Installation starts only after the user requests it.
